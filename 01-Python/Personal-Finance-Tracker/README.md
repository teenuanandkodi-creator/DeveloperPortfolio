# 💰 Personal Finance Tracker

A command-line Personal Finance Tracker built with Python.

## Features

- Add Income
- Add Expenses
- View Transactions
- View Balance
- Search Transactions
- Edit Transactions
- Delete Transactions
- Financial Reports
- Export to CSV
- Import from CSV
- Automatic JSON Storage
- Data Backup

## Technologies Used

- Python 3
- JSON
- CSV
- Git
- GitHub
